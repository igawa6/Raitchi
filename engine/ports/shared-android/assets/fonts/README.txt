shared_5.ttf is a generic, game-free NintendoExt substitute font. Its controller
icon outlines were drawn by the make_button_font.py implementation in
SuperMarioWonderRecomp (Copyright (c) 2026 BelmanteGu; MIT license in
LICENSE-ButtonGlyphs.txt). The base Fredoka font outlines are licensed under
the SIL Open Font License 1.1 (full notice in OFL-Fredoka.txt).

No console font, Nintendo artwork, or game data is included. The asset maps
NintendoExt private-use codepoints to generic button icons; its exact bytes are
tracked separately from the pinned reference checkout.
